### 💼 Modern Developer Portfolio

A clean, responsive, and professional developer portfolio showcasing my engineering projects, technical skill set, and professional curriculum vitae (CV). 

### 🚀 Live Demo

You can view the live interactive website here: **https://github.com/LusandaBanzi/My-Portfolio-/** 

### 🛠️ Built With

This portfolio was built entirely from scratch with a touch of AI using pure front-end web technologies to ensure optimal performance and minimal loading overhead: 

* **HTML5** – Semantic structural markup.
* **CSS3** – Modern responsive styling, custom animations, and layout design (Flexbox/Grid).
* **JavaScript (ES6+)** – Interactive UI elements, smooth scrolling animations, and dynamic project filtering.

### ✨ Key Features

* **Dynamic Project Showcases:** Filterable gallery featuring detailed write-ups and links to individual repositories.
* **Interactive Skills Section:** Visual matrix showcasing my technical expertise and proficiency.
* **Digital CV Access:** Integrated view and seamless download option for my professional resume.
* **Fully Responsive Design:** Tailored user experience optimized for desktop, tablet, and mobile displays.
* **Dark / Light Mode Toggle:** Comfortable reading preferences for recruiters and engineers alike.
